# Office Express

Sistema web desenvolvido como projeto acadêmico para praticar a criação e estruturação de interfaces de autenticação.

##  Sobre o projeto

O **Office Express** é uma aplicação web que apresenta uma interface de login e cadastro de usuários, desenvolvida com foco em **organização visual, usabilidade e estruturação de páginas web**.

O projeto foi desenvolvido durante minha formação em **Técnico em Desenvolvimento de Sistemas**, com o objetivo de colocar em prática conhecimentos de desenvolvimento Front-end.

##  Funcionalidades

* Tela de login
* Campo para e-mail
* Campo para senha
* Acesso à área de cadastro
* Interface responsiva
* Organização de elementos e formulários
* Navegação entre as páginas

##  Tecnologias utilizadas

* **HTML5** — estrutura das páginas
* **CSS3** — estilização e layout
* **JavaScript** — interações e validações da interface
